# ระบบศิลป์ไพ่ยิปซี (Tarot Art System)

ภาพประกอบไพ่ทั้งหมด **วาดขึ้นใหม่เป็น SVG vector ต้นฉบับของโปรเจกต์นี้**
ไม่มีการคัดลอก/ดาวน์โหลด/ตัดต่อภาพจากสำรับไพ่ที่มีลิขสิทธิ์ใด ๆ

## แนวทางลิขสิทธิ์

1. **ไม่ใช้ภาพจากสำรับที่มีลิขสิทธิ์** เช่น Rider–Waite–Smith (ยังมีลิขสิทธิ์ในบางประเทศ), Thoth Deck ฯลฯ
2. **อ้างอิงเฉพาะ "สัญลักษณ์" ที่เป็นสากล** — ความหมายและองค์ประกอบของไพ่แต่ละใบ
   (เช่น The Fool มีสุนัข + หน้าผา, Justice มีตาชั่ง + ดาบ) ซึ่งเป็นข้อเท็จจริงสาธารณะ
   ที่มีรายละเอียดตรงกับหน้า [Major Arcana — Wikipedia](https://en.wikipedia.org/wiki/Major_Arcana)
   และหน้าเทศกาล [Songkran (Thailand)](https://en.wikipedia.org/wiki/Songkran_(Thailand)),
   [Loy Krathong](https://en.wikipedia.org/wiki/Loy_Krathong)
3. **สไตล์ภาพเป็นการ์ตูนเรขาคณิตแบบแบน (flat cartoon)** ที่วาดด้วยโค้ดล้วน
   ใน `js/art/*.js` — ทุกเส้นทุกรูปร่างถูกสร้างขึ้นใหม่ ไม่ trace จากภาพต้นฉบับ
4. ข้อความบนไพ่ (ชื่อไทย/อังกฤษ) มาจาก `data/cards.json` ของโปรเจกต์

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `js/art/helpers.js` | ตัวช่วยวาด SVG (วงกลม ดาว หัวใจ ดอกบัว เปลวเทียน ค้างคาว เกล็ดหิมะ ลายกนก ฯลฯ) |
| `js/art/themes.js` | พาเลตสี + โมทีฟของธีม 7 แบบ |
| `js/art/fronts.js` | หน้าไพ่ 78 ใบ (Major 22 ภาพเฉพาะใบ + Minor pip/court) |
| `js/art/backs.js` | หลังไพ่ 7 แบบตามเทศกาล |
| `js/art/tarot-art.js` | API กลาง: `renderCardFront` / `renderCardBack` / `paintFront` / `paintBack` / `renderBack` |
| `cards-preview.html` + `js/cards-preview.js` | หน้าชมสำรับทั้ง 78 ใบ เปลี่ยนธีมได้ |

## ธีมทั้ง 7 แบบ

| id | ชื่อ | โมทีฟหลังไพ่ | มุมกรอบ | เทศกาล/ช่วงเวลา |
|---|---|---|---|---|
| `standard` | มนตราสยาม | ดาวแปดแฉกวงกนก | กนก | ใช้ปกติทั้งปี |
| `songkran` | สงกรานต์ | หยดน้ำ + ดวงอาทิตย์ + คลื่น | หยดน้ำ | 11–17 เม.ย. (วันสงกรานต์ 13–15 เม.ย. ตาม Wikipedia) |
| `loy-krathong` | ลอยกระทง | กระทง + โคมลอย + จันทร์เสี้ยว | โคมไฟ | 1–20 พ.ย. (วันเพ็ญเดือน 12 ไทย ~พฤศจิกายน) |
| `halloween` | ฮาโลวีน | จันทร์ฟักทอง + ค้างคาว | ค้างคาว | 24–31 ต.ค. (ฮาโลวีน 31 ต.ค.) |
| `christmas` | คริสต์มาส | เกล็ดหิมะ + ของขวัญ + ดาว | เกล็ดหิมะ | 20 ธ.ค. – 5 ม.ค. |
| `valentine` | วาเลนไทน์ | หัวใจ + ลูกศรคิวปิดองค์ | หัวใจ | 10–16 ก.พ. |
| `minimalist` | มินิมอล | สามเหลี่ยมซ้อน | เส้นเฉียง | เลือกเองได้ |

การสลับธีมทำงาน 2 ทาง:
- **อัตโนมัติตามวันที่** (เขตเวลา Asia/Bangkok) ผ่าน `data/seasons.json`
- **เลือกเอง** จาก dropdown มุมขวาบน (จำค่าไว้ใน localStorage) — เหมือนเดิมทุกอย่าง

## หมายเหตุการออกแบบ

- ตัวเลข Major Arcana ใช้เลขโรมันบนหัวไพ่ ตัวเลข Minor ใช้อารบิก ส่วนการ์ดตัวต่อ (Page/Knight/Queen/King) ใช้สัญลักษณ์ ✦
- หน้าไพ่ Minor 1–10 จัดวางตำแหน่ง pip แบบเรขาคณิตอ่านง่าย (แนวเดียวกับไพ่โป๊กเกอร์)
- การ์ดตัวต่อแยกด้วยอาภรณ์สีชุด + เครื่องประดับศีรษะเฉพาะตัว (หมวกแก๊ป/กันน็อค/มงกุฎโค้ง/มงกุฎแหลม)
